Últimos saldos entregados

Cada compra pagada genera un saldo con código único. Se marca "usado" cuando lo aplican en otra compra.

¿Cuándo vence el saldo?

Aplica a los saldos nuevos. Los que ya se entregaron mantienen su fecha.

días

Si la fecha ya pasó o faltan menos de 3 días, se usa la cantidad de días.

Cómo se calcula

Escalas

Según cuánto gastó, cuánto saldo recibe. Cada escala empieza donde termina la anterior. Dejá "hasta" vacío en la última para "sin tope". Compra mínima = cuánto tiene que gastar para poder usar el saldo (vacío = sin mínimo).
